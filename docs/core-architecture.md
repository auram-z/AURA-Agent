# هسته هوش مصنوعی اختصاصی AURA

نسخه معماری: **3.0-core**

## اصول طراحی

| اصل | توضیح |
|-----|--------|
| 🔒 **بدون وابستگی اجباری** | بدون کلید API هم پاسخ می‌دهد (حالت Local) |
| 📡 **آنلاین + آفلاین** | انتخاب پویا بر اساس شبکه و سخت‌افزار |
| 💾 **حافظه و دانش اختصاصی** | MemoryStore + KnowledgeStore روی دستگاه |
| 📈 **یادگیری** | Feedback + TrainingPipeline (JSONL) |
| 📱 **چندپلتفرم** | Android (فعلی) · Web · iOS/Desktop (لایه مشترک) |
| ⚙️ **آگاهی از سخت‌افزار** | RAM/CPU/شبکه → انتخاب backend |

## لایه‌ها

```
┌─────────────────────────────────────┐
│  UI (Android / Web / iOS / …)       │
├─────────────────────────────────────┤
│  AuraCore (کنترل مرکزی)             │
│  · Policy: prefer_local / hybrid    │
│  · HardwareProfiler                 │
├──────────┬──────────┬───────────────┤
│ Local    │ OnDevice │ Remote (اختیاری)│
│ Rule/KB  │ LLM stub │ xAI/OpenAI/…  │
├──────────┴──────────┴───────────────┤
│  Memory · Knowledge · Feedback      │
└─────────────────────────────────────┘
```

## حالت‌های اجرا (RuntimeMode)

1. **LOCAL_ONLY** — فقط قوانین + حافظه + دانش روی دستگاه (بدون شبکه)
2. **HYBRID** — محلی اول؛ برای سوالات پیچیده در صورت آنلاین → Remote
3. **REMOTE_PREFERRED** — مدل ابری با fallback محلی

## تشخیص سخت‌افزار

| شرط | پیشنهاد |
|-----|---------|
| آفلاین | LOCAL_ONLY |
| RAM < 3GB | بدون OnDevice سنگین |
| RAM ≥ 6GB + مدل محلی نصب‌شده | OnDevice |
| آنلاین + کلید API | Remote در صورت نیاز |

## استقلال از شرکت‌های دیگر

- API ابری **اختیاری** است (`AURA_API_KEY` می‌تواند خالی باشد).
- دانش و حافظه فقط روی دستگاه شماست.
- OnDevice واقعی (GGUF / MediaPipe) در فاز بعدی به `OnDeviceBackend` وصل می‌شود.
