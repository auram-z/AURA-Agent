# AURA Learning System — v2.4 + یادگیری خودکار

## یادگیری خودکار (پیش‌فرض: روشن)

| چه چیزی | رفتار وقتی Auto روشن است |
|---------|---------------------------|
| دانش (LLM extract) | ذخیره فوری بدون دیالوگ |
| بازخورد اصلاحی («اشتباهه…») | ذخیره فوری |
| «یادت باشه …» | ذخیره فوری در notes |
| نام کاربر («اسم من…») | **همیشه تأیید** (حساس) |
| ترجیحات ضمنی («دوست دارم…») | ذخیره خودکار |
| 👍👎 | همیشه بدون دیالوگ |

### دستورات صوتی/متنی
- «یادگیری خودکار روشن» / «فعال»
- «یادگیری خودکار خاموش»
- «وضعیت یادگیری»

### تزریق به مدل
حافظه + آخرین دانش‌ها در هر درخواست به context مدل اضافه می‌شوند تا AURA واقعاً «یادگرفته» پاسخ دهد.
