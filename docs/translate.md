# ترجمه و زیرنویس خودکار → فارسی

نسخه **2.5.0-translate**

## قابلیت‌ها

| نوع | روش |
|-----|------|
| **متن هر زبانی** | `ترجمه کن: ...` |
| **زیرنویس SRT/VTT** | `زیرنویس فارسی:` + محتوا |
| **عکس** | دکمه 📷 یا Share از گالری |
| **اشتراک از اپ‌های دیگر** | Share → AURA |

## معماری

```
media/
├── TranslateService.kt      # ترجمه با مدل xAI → فارسی
├── ImageTextExtractor.kt    # Vision / استخراج متن عکس
├── SubtitleParser.kt        # SRT / VTT
└── MediaTranslateManager.kt # یکپارچه‌سازی
```

## نکته فیلم

برای فیلم کامل: فایل زیرنویس (SRT) را استخراج یا دانلود کنید و با دستور «زیرنویس فارسی» بفرستید.
استخراج صوت از ویدیو (ASR) در نسخه بعدی با مدل گفتار اضافه می‌شود.

*At your service.*
