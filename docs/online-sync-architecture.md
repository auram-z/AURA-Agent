# نسخه آنلاین AURA و همگام‌سازی با اندروید

نسخه: **1.0** — ۲۵ اکتبر ۲۰۲۶

## هدف

- **نسخه آنلاین (Web)** در اینترنت آزاد جهان جستجو کند و دانش جمع کند.
- وقتی گوشی **آنلاین** شد، دانش بین نسخه وب و نسخه اندروید **رد و بدل** شود.

---

## جریان همگام‌سازی

1. **وب همیشه آنلاین** → جستجو و ذخیره در `localStorage` / IndexedDB
2. کاربر در وب «خروجی بسته دانش» می‌گیرد (دانلود JSON)
3. وقتی گوشی آنلاین شد:
   - فایل را به اندروید می‌فرستد (اشتراک / دانلود / URL)
   - یا اندروید از یک URL امن (تحت کنترل کاربر) بسته را می‌کشد
4. `KnowledgeSyncService` روی اندروید:
   - تکراری‌ها را حذف می‌کند
   - `confidence` بالاتر را نگه می‌دارد
   - دانش جدید را به `KnowledgeStore` اضافه می‌کند
5. مسیر معکوس: اندروید هم می‌تواند بسته صادر کند تا وب آن را وارد کند

## اصول امنیتی

- فقط HTTPS برای URL همگام‌سازی
- بدون وابستگی اجباری به سرور شخص ثالث
- کلید API فقط روی دستگاه/مرورگر خود کاربر
- کاربر کنترل کامل روی محل ذخیره دانش دارد
