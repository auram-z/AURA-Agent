## ✨ ویژگی‌ها

### هسته
- چت مدرن هولوگرافیک + شخصیت جارویس
- صدا (STT + TTS)
- ابزارهای دستگاه

### 📈 معامله‌گری (v1)
- **دو بازار:** بورس ایران + کریپتو
- **Paper Trading** (شبیه‌سازی — بدون پول واقعی)
- **مدیریت ریسک سخت‌گیرانه:**
  - حداکثر ریسک هر معامله: 1.5%
  - سقف ضرر روزانه: 3% → Kill Switch
  - حداکثر پوزیشن باز
  - حداقل اعتماد سیگنال
- اسکن بازار + سفارش دستی/خودکار
- لاگ کامل معاملات

> ⚠️ معامله واقعی (LIVE) هنوز فعال نیست. فقط Paper Trading.
