# AURA در سطح Grok / ChatGPT / Gemini — v2.6

## چه چیزی اضافه شد؟

| قابلیت | توضیح |
|--------|--------|
| **System prompt پیشرفته** | استدلال، کد، صداقت، استفاده از جستجو |
| **جستجوی وب** | DuckDuckGo + ویکی‌پدیا |
| **AgentOrchestrator** | تشخیص خودکار نیاز به search → تزریق نتیجه → پاسخ |
| **max_tokens بالاتر** | پاسخ‌های بلندتر (۸۱۹۲) |
| **تاریخچه گسترده‌تر** | تا ۸۰ پیام |

## دستورات جستجو

- `جستجو کن: قیمت بیتکوین`
- `سرچ آخرین اخبار هوش مصنوعی`
- یا سوالات طبیعی: «امروز چه خبری از بورس است؟»

AURA خودش تشخیص می‌دهد چه زمانی باید وب را جستجو کند.

## معماری

```
ai/
├── AuraAiService.kt       # مدل + prompt سطح بالا
├── WebSearchService.kt    # DDG + Wikipedia
├── AgentOrchestrator.kt   # حلقه ایجنت
└── AuraViewModel.kt       # اتصال به UI
```

## محدودیت صادقانه

- قدرت استدلال وابسته به مدل API شماست (مثلاً grok-beta / grok-2 / …).
- جستجو رایگان است و به اندازه Google Search کامل نیست.
- برای بهترین نتیجه مدل قوی‌تر در `AURA_MODEL` تنظیم کنید.

*At your service.*
