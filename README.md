# 🌌 AURA-Agent

**دستیار هوشمند شخصی همه‌کاره — الهام‌گرفته از جارویس (Jarvis)**

> *"At your service."*

AURA یک ایجنت هوشمند بی‌نقص روی اندروید است که مثل جارویس رفتار می‌کند.

الهام‌گرفته از بهترین سیستم‌های ۲۰۲۶ (از جمله OpenClaw، Hermes Agent، OpenJarvis و Personal Jarvis).

## 🚀 راه‌اندازی

### پیش‌نیازها
- Android Studio (Hedgehog یا جدیدتر)
- JDK 17+
- API Key از xAI / OpenAI / Gemini یا هر endpoint سازگار

### نصب

```bash
git clone https://github.com/auram-z/AURA-Agent.git
cd AURA-Agent
```

فایل `local.properties` را بسازید:

```properties
AURA_API_KEY=your_api_key_here
AURA_BASE_URL=https://api.x.ai/v1
AURA_MODEL=grok-beta
```

سپس Sync و Run کنید.
