# هسته فوق‌هوشمند مستقل AURA

نسخه معماری: **3.2-super-independent**

## اصول طراحی

| اصل | توضیح |
|-----|--------|
| 🔒 **استقلال کامل** | بدون کلید API هم پاسخ می‌دهد (Local همیشه فعال) |
| 🧠 **استدلال مبتنی بر اطمینان** | هر پاسخ محلی `confidence` دارد؛ در صورت ضعف به لایه بالاتر می‌رود |
| 📡 **آنلاین اختیاری** | شبکه فقط وقتی شما بخواهید |
| 💾 **دانش اختصاصی** | KnowledgeStore با source، confidence، claims، زبان |
| 🔍 **تشخیص تناقض** | ContradictionDetector روی پایگاه دانش |
| 📈 **یادگیری مستمر** | ContinuousLearner ۲۴ ساعته + همگام با نسخه آنلاین |
| ⚙️ **آگاهی از سخت‌افزار** | RAM/CPU/شبکه → مسیریابی backend |

## رفتار هسته مستقل (Local)

1. جستجو در پایگاه دانش با امتیاز اطمینان
2. ترکیب چند منبع مرتبط
3. اعلام صریح سطح اطمینان
4. در صورت تناقض یا اطمینان پایین → هشدار یا ارجاع به Hybrid/آنلاین
5. بدون اینترنت: کامل روی دستگاه کار می‌کند

## حالت‌های اجرا

| سیاست | رفتار |
|--------|--------|
| **LOCAL_ONLY** | فقط Local + OnDevice — صفر تماس خارجی |
| **HYBRID** | Local اول؛ اگر confidence < 0.7 و آنلاین → Remote |
| **REMOTE_PREFERRED** | ابری اول، با fallback محلی |

## دستورات هسته

- `وضعیت هسته` — گزارش کامل
- `سخت‌افزار` — RAM / CPU / شبکه
- `فقط محلی` / `حالت ترکیبی` / `ترجیح ابری`
- `وضعیت دانش` / `تناقض`

## استقلال از شرکت‌های دیگر

- API ابری **کاملاً اختیاری** است.
- دانش و حافظه فقط روی دستگاه (یا بسته همگام‌سازی تحت کنترل شما).
- نسخه آنلاین هم می‌تواند بدون کلید، فقط با جستجوی آزاد وب کار کند.
